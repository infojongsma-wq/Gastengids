# Huisgids Markollenweg 2 — website (foto's ingebouwd)

Meerpagina-website van de gastengids, tweetalig NL/EN, installeerbaar als app.
De foto's zitten in de pagina's zelf, dus er is GEEN aparte map nodig.

## Uploaden
Upload alleen de losse bestanden naar je repo (Add file -> Upload files):
index.html, aankomst.html, het-huis.html, zwembad-tuin.html, praktisch.html,
omgeving.html, eten-drinken.html, contact.html, styles.css, app.js,
manifest.webmanifest, sw.js, vercel.json en de icon-/favicon-bestanden.
Je mag de oude map `img` en de zip in de repo verwijderen; die zijn niet meer nodig.
